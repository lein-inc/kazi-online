01

デザイン原則Principles

KAZI ONLINEは1932年創刊の月刊『Kazi』を母体とするマリンメディア。デザインは「海の上質さ」を静かに伝えることを目的とし、装飾ではなく余白・細線・文字組で品位を作る。

  • クワイエット・プレミアム — 角丸なし（border-radius: 0）、太い装飾より1pxの細線、色数を絞りletter-spacingで高級感を出す。
  • 白がベース、ネイビーは特別な場所にだけ — 通常ページは白背景＋KAZIブルーのアクセント。ダークネイビーの世界観はSea Dream Club（会員）文脈に限定する。
  • Serifは情緒、Sansは情報 — キャッチコピー・CTA見出し・ペイウォールなど感情に訴える場面のみNoto Serif JP。記事・UI・ナビはNoto Sans JP。英字ラベルはInter。
  • CTAは一本化 — 同一ページに同じ訴求のCTAを重複させない。SDC入会訴求はフッター上のBig CTAをマスターとする。
  • カードUIはサイト全体で統一 — 記事カードは「本文左・サムネイル右（120×80px）」の横型2カラムを共通フォーマットとする。
  • 広告は世界観の内側に — ネイティブ広告は記事カードと同じトーンで設計し、「AD」表記で区別する。

04

レイアウト・グリッドLayout & Grid

  • コンテンツ最大幅 1100px（記事系）。ヘッダー内側は最大1600px。
  • 記事・一覧ページは「メイン + 右サイドバー300px」の2カラムgrid。メイン側には必ず min-width: 0 を指定する（gridの縮小不能事故防止）。
  • サイドバーは768px以下で非表示。1024px閾値で消すとBig CTAとの訴求バランスが崩れるため768pxとする。
  • ヘッダーは sticky。上端にKAZIブルーのグラデーションライン（#1E3A5F → #2C5F8A → #3A7AB5、2px）を敷く。
  • main側に max-width を掛けない — サイドバーgridが崩れる原因になった過去事故あり（全43ページ一括修正済み）。

Big CTA（SDC入会・全ページ共通）

KAZI SeaDream Club

海を、もっと近くに。

会員限定記事・プレミアム・アーカイブ配信・優先案内。
あなたのマリンライフを深めるメンバーシップ。

無料で登録する
  • 背景 #0A0F1A、見出しはSerif 30px/400、余白は上下100px。フッター直上に全ページ設置。
  • 同一ページ内のSDC訴求はBig CTAに一本化。サイドバーSDCバナーはコンパクト版のみ併用可（大型バナーの重複は禁止）。

ペイウォール（会員限定記事）

  • 位置は目次直下（本文を読み始める前に会員価値を提示する）。
  • デザインはSDCグラデーション（165deg #0A0F1A → #1E3A5F）＋上下に1pxの青グラデーションライン。
  • 構成：Eyebrow（Inter 10px/4px字間）→ Serif見出し26px → 説明文 → 特典アイコン3つ → 登録ボタン → ログインリンク。
  • 本番実装では未ログイン時に本文2段落または200字でカット（短文記事はフォールバック処理）。ログインは redirect_to 付きで記事に復帰させる。

スライダー・埋め込み・画像

  • ヒーロー/フォトスライダーは Swiper 11（self-host）。paginationカスタムは specificity 罠があるため !important 指定が必須。
  • 記事内スライダーはGutenbergカスタムブロック kazi/photo-slider（ライトボックス付き）。
  • 埋め込み16:9枠は is-type-video に限定。Yahoo!ニュース等の外部リンクはOGPリンクカード（kazi-linkcard）で表示。
  • 出版物表紙はアスペクト比 704:1000・object-fit: contain・bottom center・白背景で統一。
  • 記事画像はWebP必須。figure/img の margin はテーマ汎用ルールに潰されるため、カスタムブロック内では !important で上書きする。
06

Sea Dream Club ブランドルールSDC Brand Rules

会員組織の名称・世界観の適用範囲は、ブラッシュアップの過程で以下に確定した。

  • 正式名称は「KAZI SeaDream Club」（略称SDC）。表記ゆれ（Sea Dream Club等）はブラッシュアップで統一済み。新規制作物もこの表記に従う。
  • 会員特典は3本柱 — ①継続性（プレミアム・アーカイブ配信）②プレミアム感（会員限定記事）③体験価値（イベント優先案内）。訴求文はこの柱に沿って書く。
  • 会員デジタル機能 — ブックマーク・閲覧履歴・お気に入りマリーナ・優先通知・メルマガ。マイページに集約。
  • ダーク世界観の適用範囲 — Big CTA・ペイウォール・SDCランディング・フッターのみ。マイページは白ベースでヘッダー帯のみSDC世界観（全面ダークは可読性・実用性の面で不採用となった経緯あり）。
  • ポップアップは画面中央に大きく表示（記事スクロール時のSDC訴求）。小さなコーナー表示は不採用。
  • デジタル雑誌という表現は使わない — 「プレミアム・アーカイブ配信」と呼ぶ。
07

広告配置モデルAd Placement

  • 配置枠は PC 5枠 / SP 3枠。SPはフッター上バナーを含む。詳細は広告バナー配置モデルを参照。
  • サイドバーのネイティブ広告は縦長2:3。記事カードと同じトーンで「AD」ラベルを付ける。
  • マイページ内にも広告枠3枠を確保（会員向け配信面）。
  • 広告が世界観を壊さないよう、枠のサイズ・位置は本モデルで固定し、ページごとの独自配置はしない。
08

UXルール（ブラッシュアップの教訓）UX Rules

2026年3月〜9月のワイヤーフレーム改修51回と本番公開後の運用改善から確立したUX上の決定事項。

  • CTA重複は離脱を生む — サイドバーSDCバナーとBig CTAの二重訴求を整理し、Big CTAをマスターに一本化した。新規セクション追加時も訴求の重複を必ず確認する。
  • 会員登録フォームはその場に置かない — ページ内フォームより「登録ページへの遷移ボタン」の方が導線として明快。
  • ペイウォールは目次直下 — 記事末尾では気づかれない。読む前に価値を提示する。
  • ログイン後は元の記事に戻す — 会員限定記事からのログインは redirect_to 付きで記事へ復帰。マイページに飛ばさない。
  • CAPTCHAは大きく読みやすく — SiteGuard画像を160×54pxに大型化・低ノイズ化（離脱要因の除去）。
  • 閉鎖・移転URLはsoft-404にしない — 旧URLはパターン一括＋個別JSONマップ（677件）でリダイレクト。死記事はトップではなく /new へ。
  • SPではサイドバーを捨てる — 768px以下はメイン1カラム＋Big CTA＋フッターバナーに絞る。
  • 一覧ページは16件表示を標準とする。
  • 動画索引（movie_index）は「頭カナ」で五十音分類 — タイトルへのプレフィックス付与や「その他」分類は廃止。
09

実装ルール（本番運用）Implementation

最重要：本番テーマ（kazi-online-v2）はXserver直接編集がマスター。ローカルコピーはstaleであり、scpでの上書きは厳禁。
  • CSSは .css と .min.css の両方を必ず同期し、テーマバージョンを更新する。本番が読むのは .min.css。
  • CSSキャッシュは1年immutable（.htaccess）。?ver=KAZI_THEME_VERSION の強制付与で更新を反映させる。
  • 編集したPHPは php -l を通す。本番直接編集の前に .bak_YYYYMMDD を同階層に残す。
  • OG画像：サイト既定はKAZIロゴ、連載詳細はカバー画像。画像変換時はJPEG形式を明示する（中身PNGの偽装jpgはSNSでロゴにフォールバックする）。
  • 連載は3階層（親 → 子連載 → 記事）で一元管理。記事下の連載カード・公開予定はテーマが自動描画するため、投稿画面での個別設定は不要。
  • body > .mypage-sidebar { display: none } は削除禁止（マイページナビが全ページのフッター下に展開する事故防止）。

ブラッシュアップ履歴Design History

ワイヤーフレーム51コミット＋本番運用改善の主要マイルストーン。本ガイドラインはこの最終到達点を規範化したもの。

Phase 1 — 基盤
初期ワイヤーフレーム制作・デザイン大幅リニューアル
全59ページのWF構築。TOP・記事詳細・全サブページのデザイン統一。サイトマップ（index）とパスワード保護を整備。
Phase 2 — 会員基盤
ログイン・認証・マイページの新デザイン統一
ログイン／パスワードリセット3ページを刷新。検索ポップアップを全ページ統一、著者記事一覧を追加。
Phase 3 — SDC世界観
Sea Dream Club 世界観の確立とSP対応
ダークネイビー×Serifのプレミアムトーンを導入し、SDC入会Big CTAを全ページに設置。チラシに基づくメッセージング全面更新と「KAZI SeaDream Club」名称統一。SPレスポンシブ対応。
Phase 4 — 収益面
広告バナー配置モデルの確立
PC5枠/SP3枠の配置・料金・imp保証を視覚化。サイドバーはSDCバナー縮小＋縦長2:3ネイティブADの構成に確定。CTA重複を整理しBig CTAへ一本化。
Phase 5 — 会員体験
会員限定記事・ペイウォール・マイページの磨き込み
ペイウォールを目次直下へ移動しSDC高級デザインに刷新。マイページは白ベース＋ヘッダーのみSDC世界観に決着。SDC特典を3本柱で具体化し、会員デジタル機能（ブックマーク・履歴・お気に入りマリーナ等）を追加。
Phase 6 — 統一・最新
カードUI横型統一・名称統一・一覧16件化（現行版）
関連記事・ブックマーク・閲覧履歴・お気に入りマリーナを横型2カラムカードに統一。SDCポップアップは中央大型表示、登録CTAは遷移ボタン化。「デジタル雑誌」を「プレミアム・アーカイブ配信」へ改称。
本番運用（2026.07.20 公開〜）
公開後の継続改善
会員限定ゲートの2段落/200字カット、CAPTCHA可読性向上、連載3階層化、OG画像統一と2,430件一括再生成、フォトスライダーブロック、OGPリンクカード、旧URL3,217件リダイレクトなどを実装。
